# Enterprise Retail Analytics and Demand Forecasting System

## 📌 Project Overview

The Enterprise Retail Analytics and Demand Forecasting System is a machine learning-based application developed to help retail businesses analyze historical sales data and predict future sales demand. The system provides valuable insights into customer behavior, product performance, and sales trends, enabling businesses to make data-driven decisions.

---

## 🚀 Features

- Sales Prediction using Machine Learning
- Retail Sales Analytics Dashboard
- Interactive Streamlit Web Application
- Sales Trend Analysis
- Category-wise Sales Analysis
- Region-wise Performance Analysis
- Profit Analysis
- Data Visualization with Charts
- Easy-to-use User Interface

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/kommineniLakshmiNarayana/Enterprise-Retail-Analytics.git
```

Move into the project directory

```bash
cd Enterprise-Retail-Analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
